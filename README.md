# LORR24 experiments

This repository stores experiments. The main repository is located [here](https://github.com/Straple/LORR24)

The Data folder contains our tests and their logs. Inside the folder is a metrics_plot.pdf, which shows a comparison of the algorithms on these tests. The folder is divided into random, game, and warehouse maps. Each map stores information about 8 algorithms. Each algorithm stores the solution log, program output, metrics, and heatmaps on each test
